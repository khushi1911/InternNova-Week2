# InternNova Week 2 – Control Flow & Methods

This repository contains my Week 2 Java assignment.

The assignment focuses on Java control flow, loops, methods, method parameters, return types, and arrays.

## Tasks Covered

### Task 1 – Conditional Statements: Student Result
- Takes student name and marks in three subjects
- Calculates total marks
- Calculates percentage
- Determines Pass or Fail using if-else

### Task 2 – Loops: Number Practice
- Prints numbers from 1 to 100
- Prints even numbers from 1 to 100
- Prints odd numbers from 1 to 100
- Calculates the sum from 1 to 100

### Task 3 – Methods: Calculator
Separate methods are used for:
- Addition
- Subtraction
- Multiplication
- Division
- Modulus

### Task 4 – Method Parameters & Return Types
Methods are created to:
- Find square of a number
- Find cube of a number
- Find average of three numbers
- Find maximum of two numbers

### Task 5 – 1D Array: Student Marks
- Stores marks of 5 students in a 1D array
- Displays all marks
- Calculates total marks
- Calculates average marks
- Finds highest marks
- Finds lowest marks

### Task 6 – 2D Array: Matrix Operations
- Creates a 3 × 3 matrix
- Takes matrix elements as input
- Displays the matrix
- Calculates the sum of all elements

## Technologies Used

- Java
- JDK 26
- VS Code
